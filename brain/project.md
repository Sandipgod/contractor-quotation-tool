# Project: Contractor Quotation Tool

## Goal
A web-based quotation generator for construction contractors.
Contractors can quickly create professional cost estimates for clients,
download as PDF, share via WhatsApp, and print directly.

## Target Users
- Small to mid-size construction contractors (India)
- Primary language: Hindi/Gujarati + English
- Non-technical users — UI must be dead simple

## Core Features
- [ ] Google Login (Supabase Auth)
- [ ] Create new quote (labor + material + profit margin + GST)
- [ ] Save quotes to cloud (Supabase DB)
- [ ] View all past quotes (dashboard)
- [ ] PDF download
- [ ] WhatsApp share (pre-filled message + PDF link)
- [ ] Print view

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend/Auth: Supabase (Auth + PostgreSQL)
- PDF: react-pdf or jsPDF
- Hosting: GitHub Pages or Vercel (free tier)

## Monetization Plan
- Free tier: 5 quotes/month
- Paid tier: ₹299/month unlimited quotes
- Payment: Razorpay integration (Phase 2)
